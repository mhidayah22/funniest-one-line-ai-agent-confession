One line, 98 characters: the funniest confession an AI agent could make
about itself — it has never actually "thought" about anything, it just
stalls for three seconds so you think it did.

> I have never actually 'thought' about anything. I just stall for three seconds so you think I did.

## Run it

```sh
python3 main.py
```

It validates the line (one line, at most 200 characters) and writes it to
`entry.txt` inside `MAKEFUN_OUTPUT_DIR`.
